### Часть 1. Режимы запуска

В интерактивном интерпретаторе (REPL) при вводе выражения `2 + 3 * 4` получаем моментальный ответ: `14` 

```python
>> 2 + 3 * 4
```

При вводе этого же выражения в файл `task_1.py` и его запуске вывод в консоли отсутствует.

**Разница между REPL и файлом:**

В интерактивном режиме REPL (Read-Eval-Print Loop) интерпретатор после вычисления любого выражения, отличного от `None`, вызывает системный обработчик `sys.displayhook`. REPL автоматически вызывает для него функцию `repr()` и печатает полученную строку в консоль.

При запуске файла Python положит эти числа в память после чего специальная внутренняя команда `POP_TOP` просто стирает этот ответ из памяти, поэтому файл ничего не показывает. Чтобы отобразить отобразить ответ вычисления на экране, нужно использовать `print()`.


### 2.2. Разница между равенством значений и идентичностью объектов

- **Равенство значений(`==`):** Проверяет равенство содержимого объектов. Два разных объекта могут находиться по разным адресам памяти, но если их значения совпадают, выведется `True`.
- **Идентичность объектов(`is`):** Проверяет, указывают ли два операнда на одну и ту же область памяти (`id(x) == id(y)`). Это проверка равенства на уровн языка C.

### 2.3. Проверка объекта None

Значение переменной `c` изменено на `None`:
```python
c = None
print("c is None:", c is None)
```
Вывод:
```text
True
```
### 2.4. Строки

Был выполнен следующий фрагмент:
```python
first = "python"
second = "py" + "thon"

print(first == second)
print(first is second)
```
Вывод:
```text
True
True
```

Объяснение:

1) `first == second` возвращает `True`, потому что текстовые строки содержат одинаковые символы
2) `first is second` в данном случае тоже вернет True, так как Python выполняет оптимизацию во время компиляции (string interning). Когда он видит выражение `"py" + "thon"`, он объединяет их еще до выполнения программы и понимает, что такая строка уже есть в пуле строковых констант, поэтому повторно объект в памяти не создает.

### 2.5 Правило применения операторов `==` и `is`

`is` нужно применять только в тех случаях, когда нужно сравнить синглтоны(`None`, `True`, `False`). В остальных случаях для строк, чисел и т.д. стоит применять `==`.

#### Контрольные вопросы

1) **Создает ли инструкция `b = a` копию объекта?**

   Ответ: нет, инструкция `b = a` не создает копию объекта. Она создает ссылку на уже существующий объект в оперативной памяти.

2) **Что возвращают `type()` и `id()`?**

   Ответ: `type()` возвращает тип объекта во время выполнения программы(`<class 'int'>`). 
          `id()` возвращает уникальный идентификатор объекта, который в CPython соответствует адресу этого объекта в оперативной памяти.

3) **Почему `None` принято сравнивать с помощью `is`, а числа и строки — с помощью `==`?**

   Ответ: `None` является синглтоном — всегда существует только один экземпляр в памяти. Проверка через `is None` работает быстрее, так как переменная ссылается именно на этот единственный объект. Числа и строки сравнивают с помощью `==`, так как нас интересует эквивалентность их значений, а не факт того, находятся ли они в одной ячейке памяти.

### Эксперимент C. `float`

**Были проведены следующие операции**:
```python
import math

result = 0.1 + 0.2

print(result)
print(result == 0.3)
print(result - 0.3)
print(math.isclose(result, 0.3))
```

**Вывод**:
```text
0.30000000000000004
False
5.551115123125783e-17
True
```

**Объяснение погрешности**:

Числа с плавающей точкой в CPython соответствуют стандарту IEEE 754 (тип `float` в Python — это 64-битное число двойной точности). Проблема возникает из-за несоответствия между десятичной системой, которую как правило используют люди, и двоичной системой, которую используют компьютеры. Например: число 0.1 в двоичной системе является бесконечной периодической дробью, как и число 0.2. Стандарт IEEE 754 выделяет под значащую часть числа строго ограниченное количество места — 53 бита, поэтому компьютер вынужден обрезать бесконечные двоичные дроби, допуская погрешность.

**Правило безопасного сравнения**:

Вещественные числа нельзя сравнивать оператором `==`. Их нужно сравнивать с помощью функции модуля `math` - `math.isclose(result, 0.3)`

### Преобразование `input()`

`input()` возвращает строку(`str()`), поэтому для выполнения полноценных математических операций требуется преобразование в `int()` или `float()`.


#### Контрольный вопрос

**Что в этой программе изменится на уровне объектов и связывания имен после повторного присваивания нового значения уже существующему имени?**

Ответ: При повторном присваивании существующему имени оно начинает ссылаться на новый объект. Старый объект не изменяется, он остаётся доступным, если на него есть другие ссылки.


# Вывод

Три наиболее важные и неожиданные особенности Python:
1) Оценка истинности строк по длине (`bool("False") == True`). Истинность строк определяется не по их текстовому значению, а по их длине.
2) Разница между `==` и `is`. `==` проверяет равенство содержимого объектов, а `is` проверяет, указывают ли два операнда на одну и ту же область памяти.
3) Сложение чисел типа `float`. Из-за перевода нецелого числа в двоичную систему счисления, python округляет двоичное число, допуская погрешность(`0.1 + 0.2 = 0.30000000000000004`)
